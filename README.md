## 🛠️ Установка в браузер

> Подходит для Google Chrome, Яндекс Браузера, Microsoft Edge, Opera и других Chromium-браузеров.

1. **Распакуйте архив**
   Скачайте архив по ссылке выше и распакуйте в любую постоянную папку на компьютере (например, в `Документы`).
   > ⚠️ **Важно:** не перемещайте и не удаляйте эту папку после установки.

2. **Откройте страницу расширений**
   * **Chrome:** `chrome://extensions/`
   * **Яндекс:** `browser://tune`
   * **Edge:** `edge://extensions/`

3. **Включите «Режим разработчика»**
   Переведите тумблер **Developer mode** (в правом верхнем углу) в активное положение.

4. **Загрузите расширение**
   Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*) в левом верхнем углу и выберите распакованную папку.

5. **Закрепите иконку (опционально)**
   Кликните на иконку пазла в панели браузера и закрепите булавкой **Rometto LanguageTool**.

---

## 🔄 Обновление

1. Скачайте новый архив и распакуйте с заменой в ту же папку.
2. В `chrome://extensions/` нажмите иконку **круглой стрелки (Обновить)** на карточке расширения.
